# A&P Shoes

A&P Shoes es una aplicación web simple para gestionar productos de una tienda de zapatillas.  
Permite visualizar, consultar, crear, modificar y eliminar productos desde un menú intuitivo.
La parte hecha sería solo la del lado del administrador, todavía no esta hecha la parte del cliente que gestionara un carrito

---

## 🚀 Tecnologías utilizadas

- **JavaScript**
- **Google Fonts (Stack Sans Text)**

## 🎨 Estilos principales

- Barra de navegación centrada y con hover animado.
- Fuente personalizada desde Google Fonts.
- Imagen principal con bordes redondeados.
- Diseño minimalista pensado para una tienda.

---

## Funcionalidades

### Navegación
El menú permite acceder a:

- **Ver productos**  
- **Consultar un producto por ID**  
- **Crear producto nuevo**  
- **Modificar producto existente**  
- **Eliminar producto**
